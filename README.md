# RSL for RS-Bank

Плагин для IntelliJ IDEA 2025.1 (ветка платформы 251). При открытии макромодуля `.mac` IDEA автоматически включает подсветку и проверку RSL.

## Возможности

- Регистронезависимая подсветка ключевых слов, встроенных типов, литералов, операторов, вложенных комментариев, специальных имён и форм вывода. Цвета настраиваются в **Settings → Editor → Color Scheme → RSL**.
- Синтаксическая проверка объявлений и выражений, заголовков и закрытия макросов, классов и циклов, порядка ветвей `if/elif/else`, скобок, формальных параметров и аргументов вызовов. IDE окрашивает проблемный фрагмент в красный цвет и подчёркивает его.
- Проверки повторных объявлений в одной области видимости, констант без начального значения, записи в константы, некорректных целей присваивания и соответствия полей формы аргументам.
- Переход к объявлению (**Go to Declaration**, `Ctrl+B`) и поиск использований (**Find Usages**, `Alt+F7`) в текущем макромодуле с учётом областей видимости и без учёта регистра.

Анализ ограничен текущим макромодулем. Разрешение имён из `import`, проверка динамических свойств и типов RS-Bank остаются за средой исполнения. Правила корпоративного стиля из приложенного руководства не считаются синтаксическими ошибками. Для старых OEM-макросов выберите исходную кодировку через индикатор кодировки IDEA и используйте **Reload**.

## Сборка и установка

Готовый ZIP можно скачать в разделе [Releases](https://github.com/DoshikKing/idea-rsl-plugin/releases/latest).

Требуется JDK 21. Выполните:

```sh
./gradlew check buildPlugin
```

Команда проверяет лексер и анализатор, запускает тест интеграции с редактором и создаёт пакет `build/distributions/idea-rsl-plugin-<версия>.zip`. В IDEA установите ZIP через **Settings → Plugins → ⚙ → Install Plugin from Disk**. Для запуска отдельного экземпляра IDE с плагином используйте `./gradlew runIde`.

Если IntelliJ IDEA 2025.1 уже установлена, её SDK можно использовать для сборки через `-PplatformPath=/путь/к/IDE`.

GitHub Actions запускает проверки и сборку при push в `main` и в pull request к `main`. Готовый ZIP доступен в разделе **Artifacts** успешного запуска **Build plugin**.
